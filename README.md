# 네이버 커머스API
**커머스API**는 네이버 스마트스토어 판매자분들의 스토어 운영 활동을 돕는 API 서비스입니다. 여러 표준 기술을 바탕으로 RESTful API 규격 서비스 제공을 지향합니다.<br>
처음 사용자시라면 [커머스API센터](https://apicenter.commerce.naver.com)를 방문하시어 자세한 이용 조건과 방법을 확인하세요.

이 공간은 커머스API 기술지원을 위한 아래 리소스를 제공합니다.
- **[공지사항](../../discussions/categories/%EA%B3%B5%EC%A7%80%EC%82%AC%ED%95%AD)**: 커머스API 운영 및 기술 사양에 관한 중요 소식을 알립니다.
- **[릴리즈 노트](../../discussions/categories/%EB%A6%B4%EB%A6%AC%EC%A6%88-%EB%85%B8%ED%8A%B8)**: API 기술 사양의 변경점을 게시합니다.
- **[묻고 답하기](../../discussions/categories/%EB%AC%BB%EA%B3%A0-%EB%8B%B5%ED%95%98%EA%B8%B0)**: 기술 관련 문의를 게시하고 답변을 받습니다.
- **[자주 묻는 질문](../../discussions/categories/%EC%9E%90%EC%A3%BC-%EB%AC%BB%EB%8A%94-%EC%A7%88%EB%AC%B8)**: 사전에 정리된 질문과 답변을 게시합니다.
- **[Wiki](../../wiki)**: API 연동과 이용에 관한 가이드와 매뉴얼을 게시합니다.

## 커머스API Docs
**커머스API Docs**는 커머스API의 공식 기술 문서입니다. 제공 API 기능과 상세한 기술 규격을 확인해 보세요.
- [apicenter.commerce.naver.com/docs](https://apicenter.commerce.naver.com/docs)

## 기술문의
커머스API 이용과 연동 관련 기술문의는 [새 '묻고 답하기' 게시글 작성](../../discussions/new?category=%EB%AC%BB%EA%B3%A0-%EB%8B%B5%ED%95%98%EA%B8%B0)으로 물어보세요.
- 스마트스토어 운영, 서비스 정책 등 기술 외 문의는 [[스마트스토어 고객센터 > 1:1 문의하기]](https://help.sell.smartstore.naver.com/mail/form.help)에서 확인해 주세요.

> ### ⚠️ 게시 내용은 불특정 다수에게 즉각 공개됩니다.
> 이 공개 공간의 모든 게시 내용은 불특정 다수에게 공개되며 인터넷 검색엔진 등에 의해 외부에 게시 내용이 색인될 수 있습니다.<br>
> 공개하여선 안되는 정보는 게시 내용에 수록하지 말아주세요.

> - **유효 시간이 남은 인증 토큰 값**
> - **민감 정보**: 개인정보, 계정정보, 지불정보, 기밀/대외비 정보<br>
> _(그 밖에 공개가 부적합한 다양한 유형의 내용 포함)_
> 
> 공개 게시가 부적합한 내용이 포함된 경우 별도 통보 없이 게시 내용을 제거하거나 내용 수정을 권고할 수 있습니다.<br>
